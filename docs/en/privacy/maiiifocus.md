Local data deletion
Maiii‑Focus is a local-first app: session records and blocking rules are stored on-device and are not uploaded by default. We cannot delete device-local data remotely. To delete local data:
1. In-app: Settings → Privacy/Data → Delete local data (if available).  
2. iOS: Settings → General → iPhone Storage → find "Maiii‑Focus" → Delete App to remove app and local data.
If you need assistance, email support with app version, device model, and a device identifier; we can provide guidance but cannot delete device-local data for you.
